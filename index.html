Comment ajouter un widget dans Grist

  1. Ajouter → Ajouter une vue à la page.
  2. Choisir la vue : Personnalisée, puis Ajouter à la Page.
  3. Carte URL personnalisée : coller l'adresse ci-dessus, puis Ajouter un widget.
  4. Lire l'avertissement sur les vues de source inconnue, cocher la confirmation, Confirmer.
  5. Panneau de droite, onglet Vue → Niveau d'accès : Accès complet au document (nécessaire pour lire plusieurs tables).

Ce qui circule, et ce qui ne circule pas

Grist transmet les enregistrements au widget à l'intérieur du navigateur. Le serveur qui héberge ces pages ne voit aucune donnée du document. Ce qui est publié ici est du code, consultable et vérifiable.
